## 储备方向 A：高保真社交凭证与成交流水卡片生成器 (Social Proof / Deal Mockup Maker)

### 1. 核心定位
面向海外独立开发者（Indie Hackers）、Gumroad 数字创作者、Affiliate 营销达人、Shopify 独立站店主的“高保真成交感与社交证明生成工具”。

### 2. 市场痛点与机会
* **海外痛点**：
  * 海外创作者与销售人员极其依赖“客户真实好评”、“Stripe 收款到账截图”、“Twitter 互动推荐”来作为 Landing Page 或推文的社会认同（Social Proof）。
  * 现有海外 Fake Tweet / Fake Chat 工具极其老旧，充斥着低分辨率、错误字体、全屏垃圾弹窗广告，且缺乏针对严肃商业转化场景（如 Stripe 通知、Trustpilot 好评、iMessage 真实感谢短信）的模板。
  * Canva 虽然强大，但制作一张带精细时间戳、运营商信号、真实圆角和高斯模糊阴影的真实感截图需要 10~15 分钟，效率极低。
* **产品形态**：
  * 浏览器端极简配置：选择场景模板（iMessage / Stripe Notification / X Testimonial / ProductHunt Badge）。
  * 输入文案、金额、用户头像，右侧实时渲染 4K Retina 级别的矢量级卡片。
  * 支持一键导出无损 PNG/SVG，支持配置自定义渐变底色、3D 倾斜透视视角、阴影深度。
* **商业化模型**：
  * **基础版免费**：导出带轻量水印或仅支持 1080p。
  * **Pro 买断版 ($19 / 终身)**：4K 超高清导出、全套商业模板（Stripe/Shopify/iMessage/Discord）、商用授权、自定义品牌水印与颜色预设。
* **重启触发条件**：
  * 当 Project06 跑通 Gumroad / Stripe 收款与社媒获客后，需要一款面向 B 端/生产力属性、更高客单价（$19~$29）的产品时立即启动。

## 储备方向 B：极简文字转病毒式社交卡片 (Markdown to Viral Social Cards / LinkedIn Carousel)

### 1. 核心定位
面向 LinkedIn 思想领袖、X (Twitter) 知识博主、Substack 独立写作者的“文字转精美卡片/轮播图工具”。

### 2. 市场痛点与机会
* **海外痛点**：
  * LinkedIn 平台权重向“PDF 轮播图 (Carousel)”严重倾斜，轮播图曝光量是纯文字的 3~5 倍。
  * 创作者往往习惯在 Notion 或 Markdown 编辑器中写作，将一段金句或长清单转成 5~10 张统一审美标准的轮播图极其繁琐。
  * 国内“小红书知识图文生成器”、“微信读书排版卡片”早已将这一流程做到极致（输入 Markdown，自动根据 H2/列表切片，一键套用高食欲/高质感版式）。
* **产品形态**：
  * 左侧粘贴 Markdown，右侧实时生成 1:1 或 4:5 的切片卡片流。
  * 一键导出为标准 LinkedIn 轮播图专用的多页 PDF 或高保真图片包。
  * 内置针对海外阅读习惯的字体搭配（Inter, Newsreader, Playfair Display）与侘寂/极简暗色底纹。
* **商业化模型**：
  * **Freemium**：前 3 次免费导出，后续 $7.99/月 或 $29 终身。
* **重启触发条件**：
  * 当我们在海外社交媒体（X/LinkedIn）积累了一定粉丝与创作者私域后，该工具可作为高转化生产力 SaaS 迅速切入。
