# Project06 — KarmaDesk (数字疗愈解压转运仪)

> **一句话定位**：面向海外年轻白领、创作者与学生的极简桌面解压、转运祈福与声疗数字避难所（Aesthetic Minimalist Desk Sanctuary）。

## 核心亮点
- **零学习成本**：基于国内“电子木鱼 / 桌面烧香”爆款原型，重构契合欧美 #Manifestation 与 #LuckyGirlSyndrome 文化的情绪解压工具。
- **4 重微交互声疗**：西藏颂钵 (432Hz 铜音)、财富黄水晶、禅意溪石、客制化机械轴打字音。
- **纯原生零依赖**：单 HTML 文件 + Web Audio API 纯代码程序合成音效，首屏秒开，支持离线 PWA 运行。
- **商业化闭环**：基础版免费，高定美学主题与专属音效包采用 Gumroad / Stripe **$4.99 一次性买断**。
