## 1. 市场洞察与商业机会

### 1.1 国内验证与现象级爆款
* **国内形态**：以“电子木鱼”、“桌面烧香拜佛”、“转运壁纸/手串”为代表的赛博玄学与轻量解压工具，在小红书、抖音、微信小程序长盛不衰，单款电子木鱼下载量破千万，日活达数百万。
* **爆发底层机理**：
  1. **极低认知门槛**：零学习成本，单击/敲击即可获得毫秒级视听反馈（敲击声 + "+1" 漂浮文字）。
  2. **情绪即时抚平**：在高度内卷、焦虑的工作与学习间隙，提供 10~30 秒的“微摸鱼、微放空”。
  3. **情绪价值与好运寄托**：“功德+1”、“好运+1”不仅解压，还具备强大的自嘲幽默感与社交货币属性。

### 1.2 海外市场空白与文化代差
* **海外竞品痛点**：
  * **传统心理健康/冥想 App（如 Calm, Headspace）**：产品体量极重，动辄要求闭眼戴耳机听 10~15 分钟专业课程，且强制按年收取高额订阅费（$70+/年）。在远程开会、写代码、做设计等工作间隙，用户根本无法消费这种重型内容。
  * **海外现存解压小工具（如 Fidget Toys、网页小游戏）**：大多充斥着 2000 年代风格的粗糙 Flash 界面、儿童化史莱姆拉伸、或满屏遮挡视线的弹窗广告，**严重缺乏面向现代成年人的高审美产品**。
* **海外本土文化共鸣点**：
  * **#LuckyGirlSyndrome / #Manifestation**：TikTok 上关于“吸引力法则、接好运、丰盛法则”的标签播放量超过 **100 亿次**，欧美年轻人对心理暗示和“幸运玄学”极其买账。
  * **#CozyDesk / #DeskSetup 美学**：远程办公群体对桌面整洁、极简侘寂风、Lo-fi 治愈系桌面具有极高的审美认同。
  * **声疗与正念（Sound Healing & ASMR）**：颂钵（Tibetan Singing Bowl）、白噪音、客制化机械键盘 Thock 轴音效在海外 YouTube / TikTok 流量巨大。
* **产品定位**：**一款无需注册、无广告侵扰、专为桌面摸鱼与防 Burnout 设计的高颜值“微禅意与转运”数字避难所 (Aesthetic Minimalist Desk Sanctuary)**。

## 2. 目标用户画像 (Target Personas)

### 画像 1：Sarah，28 岁，远程 UI/UX 设计师（美国西雅图）
* **现状**：每天面对 Figma 和无穷无尽的 Slack 消息，午后经常陷入创造力枯竭和轻度焦虑。
* **痛点**：不想打开复杂的冥想 App，只想在副屏上挂一个安静好看的窗口，改稿烦躁时敲几下回血。
* **偏好**：喜爱极简深色模式、雨声白噪音、天然水晶疗愈；极度愿意为高品质、无广告的美学软件支付 $5~$10 买断费。

### 画像 2：Liam，24 岁，自由职业独立开发者（英国伦敦）
* **现状**：一人独处写代码，相信吸引力法则（Manifestation）与“Wealth Frequency”（财富频率）。
* **痛点**：喜欢机械键盘的解压手感，需要一种“把好运和进账敲进现实”的心理锚点。
* **操作习惯**：习惯键盘快捷键盲打，敲击空格键（Spacebar）快速累加“$ Abundance”。

## 3. 核心功能规范 (Feature Specifications)

### 3.1 极简拟物与声疗引擎 (Interactive Audio-Tactile Engine)
基于 Web Audio API 纯原生合成与无损采样，实现 0 延迟、带自然共鸣衰减的立体声敲击体验。MVP 包含 4 类本土化解压物体：

| 物件名称 | 视觉形态 | 声学特性 | 默认飘字动效 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **Tibetan Singing Bowl (西藏颂钵)** | 极简黄铜磨砂微光钵体 | 432Hz 悠远共鸣铜音（带微颤泛音） | `Peace +1` | 情绪焦虑、微冥想 |
| **Wealth Crystal (丰盛黄水晶)** | 棱角折射光芒的半透明晶体 | 清脆灵动的空灵晶石音 | `Abundance +$1` | 搞钱提气、开单转运 |
| **Zen River Stone (禅意溪石)** | 侘寂风圆润深灰色溪水鹅卵石 | 沉稳内敛的泥土/岩石低频轻叩 | `Stress -1` | 烦躁降火、深呼吸 |
| **Thocky Switch (客制化机械轴)** | 极简磨砂机械键盘单个轴体 | 饱满清脆的客制化 Linear 轴打字音 | `Focus +1` | 进入心流、敲代码摸鱼 |

### 3.2 视觉微动效与正反馈机制 (Micro-Interactions)
1. **粒子光晕与物理震颤**：
   * 点击或按下空格键时，物体产生 3% 的弹性缩放（Squish & Bounce）与柔和光环扩散。
   * 飘字从点击点缓缓升起，伴随高斯模糊渐隐消失（支持在设置中自定义文案）。
2. **极简统计计数器 (Local Counter)**：
   * 记录“今日敲击次数”与“当前冥想总善念”，纯本地 `localStorage` 存储，100% 隐私安全，零数据追踪。
3. **呼吸光环 (Breathing Halo)**：
   * 提供可选的 4-7-8 极简深呼吸微弱节奏光环，辅助打工人调节呼吸。
4. **一键防摸鱼老板键 (Stealth Mode)**：
   * 按下键盘 `Esc` 或 `H`，界面瞬间转为极简数字时钟或名言屏保，避免在办公室被窥屏。

### 3.3 沉浸背景氛围音混音器 (Ambient Layer)
支持在敲击声下方叠加大自然低分贝白噪音（可调节音量）：
* `Soft Rain` (屋檐细雨)
* `Cozy Fireplace` (壁炉柴火轻微噼啪声)
* `Forest Wind` (松林清风)

## 5. 技术架构与交付形态

* **架构**：纯前端单页架构（HTML5 + Tailwind CSS + 原生 JavaScript + Web Audio API）。
* **优势**：
  * **零服务器运维成本**：静态页面可直接托管于 Vercel / Cloudflare Pages / GitHub Pages，全球 Edge CDN 加速。
  * **极速首屏**：首屏加载在 150ms 以内，无庞大前端框架负担。
  * **安全合规**：无需数据库，完全本地存储，天然规避 GDPR / CCPA 隐私合规风险。
* **收银链路**：直接嵌入 Gumroad Overlay 模态弹窗或 Stripe Payment Link，支付成功后自动写入 LocalStorage Token 激活 Pro 特权。
